# Calculator

A simple and functional web-based calculator built with HTML, CSS and JavaScript. The project features a clean user interface and supports basic arithmetic operations.

## Features

- Addition, subtraction, multiplication and division
- Interactive calculator interface
- Clear and reset functionality
- Responsive layout

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Purpose

This project was created to practice fundamental web development skills, including HTML structure, CSS styling and JavaScript functionality.
